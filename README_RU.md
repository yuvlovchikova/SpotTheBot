# Spot the Bot: семантические траектории естественного языка

Дипломный проект НИУ ВШЭ (2023) о различении текстов, написанных человеком и сгенерированных моделью, через структурное представление языка.

Вместо опоры только на поверхностные текстовые признаки проект представляет текст как траекторию в семантическом пространстве и исследует графовые свойства этой траектории.

## Подход

Исследовательский пайплайн включает:

1. предобработку корпусов на русском и английском языках;
2. TF-IDF-векторизацию;
3. снижение размерности с помощью SVD;
4. представление слов векторами и построение текстовых последовательностей;
5. построение семантических траекторий по тексту;
6. построение графов на основе данных;
7. расчёт графовых метрик и эксперименты по классификации текстов для разделения человеческих и сгенерированных текстов.

## Стек

Python · NumPy · pandas · SciPy · NetworkX · Ray · Jupyter

## Структура репозитория

- `EnPreprocessing/` — предобработка английских текстов, TF-IDF/SVD и векторизация;
- `Russian/` — предобработка русских текстов и построение признаков;
- `Graph/` — построение графов, графовые метрики, анализ траекторий и эксперименты по классификации;
- `TextGenBot/` — инструменты для генерации машинных текстов, использованных в исследовательском пайплайне;
- `EpubToTXT.ipynb` — утилита для преобразования исходных текстов в рабочий текстовый формат.

## Контекст

Репозиторий сохраняет исходный исследовательский процесс дипломной работы, а не представляет собой production-пакет. Часть ноутбуков запускалась в локальном исследовательском окружении, поэтому в них сохранились исторические абсолютные пути и кэшированные результаты.
